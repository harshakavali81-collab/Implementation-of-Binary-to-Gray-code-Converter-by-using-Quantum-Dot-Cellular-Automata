```bash
git clone https://github.com/harshakavali81-collab/Implementation-of-Binary-to-Gray-code-Converter-by-using-Quantum-Dot-Cellular-Automata.git
cd Implementation-of-Binary-to-Gray-code-Converter-by-using-Quantum-Dot-Cellular-Automata

Review [the project explanation](docs/PROJECT_EXPLANATION.md) before running a compatible Verilog simulator.
