# Supplied Source Materials

The repository package includes four uploaded source files:

1. `Implementation of Binary to Gray Code Converter in Quantum Dot Cellular Automata mini project.pdf` — main 55-page academic project report.
2. `Mini Project PPT.pptx` — 18-slide project presentation.
3. `BCD to GCD Project Acknowledgement.docx` — 7-page document containing XOR, 2-bit and 4-bit Verilog programs and testbench material.
4. `Journal Publish paper.docx` — 8-page 2024 paper on integrating GPS/GSM technologies for a women-safety device.

The fourth item is thematically separate from the QCA converter project and is retained as supplied source material rather than treated as part of the converter implementation.
